# Skill Check

## Check
1. **Description:** Says what it does and when to use it? Contains concrete trigger phrases (DE + EN)?
2. **Overlap:** Does another installed skill trigger on the same phrases? If yes, sharpen the descriptions or merge.
3. **Length:** SKILL.md short and scannable? Move long references or templates into separate files and link them.
4. **Instructions:** Clear steps, a "Don't" section, and a defined output?
5. **Language:** DE and EN versions consistent?

## Output
- Verdict per point: OK / fix
- Concrete fix as a diff or rewritten section
- 3 test prompts that should trigger the skill, and 1 that shouldn't
